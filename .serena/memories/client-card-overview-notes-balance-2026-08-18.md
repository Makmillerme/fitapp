# Картка клієнта — шапка, Загальні, Нотатки (2026-08-18)

## Шапка
Під імʼям — **Badge статусу** (не телефон):
- ACTIVE → secondary «Активний»
- DEBT → destructive «Борг»
- PAUSED → outline «Пауза»
Лічильник балансу при 0 ставить DEBT, при >0 з DEBT повертає ACTIVE (як `updateClientBalance`).

## Вкладка Загальні
**Базова інформація** (dl):
1. Телефон
2. Telegram (`@tag` / Підключено / Не підключено)
3. Дата народження
4. Вік
5. Гендер

Немає: імʼя, статус, ціль, баланс, протипоказання.

**Баланс занять** — окремий блок під базовою інформацією.
- Текст: `N заняття/занять`
- Кнопки − / + (`Button` outline icon, Lucide Minus/Plus)
- Мінус disabled при 0 або pending
- Optimistic UI + `updateClientBalance(clientId, ±1)`
- `onClientPatched` оновлює drawer payload і список/`counts` у `ClientsView`
Автосписання з тренувань — пізніше.

## Вкладка Нотатки
1. **Протипоказання** — callout primary, поле `notes`
2. **Ціль** — картка з Target, поле `goal`
Дубль generic «Нотатки» прибрано. Редагування атрибутів — наступний крок.
