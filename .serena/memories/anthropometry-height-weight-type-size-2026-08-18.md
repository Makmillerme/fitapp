# Anthropometry height/weight SVG type size (2026-08-18)

SVG `fontSize` is in viewBox units (760×1088), so 15/18 looked ~5px on the card vs side labels `text-xs`/`text-sm`.

Scaled to roughly match those labels on a ~250px-wide SVG:
- Height badge: 132×96, number `48` / `см` `22`, weight `800`
- Weight plate: rx 164 / ry 30, number `44` / `800`
