# fitapp — product vision

## What we're building
A trainer CRM platform: each trainer gets their own workspace to manage clients and store all client-related information.

## Confirmed stack direction
- **Frontend:** Next.js (App Router), shadcn/ui
- **Database:** PostgreSQL
- **Telegram:** bot + Mini App / Web App tied to the bot (primary entry for users)

## Product shape (high level)
- Per-trainer CRM (clients, history, notes, progress — details TBD)
- Web app works in conjunction with Telegram bot (not standalone-only)
- Detailed roadmap and feature spec: **pending from user**

## Status
Vision captured 2026-07-24. No implementation started beyond `.cursor/` agent setup.
