# Антропометрія — запис заміру з олівця (2026-08-18)

## UX
Шапка `BodyMeasurementsCard`: дата «Оновлено …» якщо є знімок; **завжди** Pencil (`Записати замір`). Тексту «Поки без замірів» немає.
Тап по зоні скелета лишається підсвіткою, не edit.

## Dialog «Замір»
`src/components/clients/measurement-edit-dialog.tsx`
- Дата (сьогодні), зріст, вага, 7 зон у порядку PARTS.
- Префіл з останнього заміру / ваги клієнта. Draft скидається лише при відкритті.
- Порожні поля можна пропустити; усі порожні → toast «Вкажіть хоча б одне значення».
- Збереження: `upsertClientGeneral` — оновлює `Contact.heightCm/weightKg` і **створює новий** `ContactMeasurement` (історія), якщо є хоч один обхват або зріст.
- Після успіху toast + закриття; drawer патчить `heightCm`, `weightKg`, `latestMeasurement` через `onMeasurementsSaved`.
